⚙ G2Bulk Connection (via Cloudflare Worker)

G2Bulk key များကို Worker ထဲမှာသာ secret အနေနဲ့ ထားပြီး admin panel ကနေ Worker ကိုသာ ခေါ်ပါသည်

✓ G2Bulk Main/SMM API key များကို browser ထဲ လုံးဝ မသိမ်းတော့ပါ — Worker (wrangler secret put) ထဲမှာသာ ထားပါသည်။ ဒီနေရာမှာ ထည့်ရမှာက Worker URL နဲ့ admin token ပဲဖြစ်ပါသည်။

🔥 Firebase (Firestore)

Orders / Users / Payments / Coupons / Logs ကို Firestore ထဲမှာ real-time သိမ်းမည်

Firebase console → Project settings → General → "Your apps" → Web app config object ကို ဒီနေရာမှာ paste ထည့်ပါ။ Save & Connect လုပ်ပြီးရင် login gate ပေါ်လာပါလိမ့်မယ် — Authentication → Sign-in method → Email/Password ကို enable လုပ်ပြီး admin account တစ်ခု (Authentication → Users → Add user) ဖန်တီးထားဖို့ လိုပါတယ်။
