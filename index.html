G2Bulk Connection (via Cloudflare Worker)

G2Bulk key များကို Worker ထဲမှာသာ secret အနေနဲ့ ထားပြီး admin panel ကနေ Worker ကိုသာ ခေါ်ပါသည်

✓ G2Bulk Main/SMM API key များကို browser ထဲ လုံးဝ မသိမ်းတော့ပါ — Worker (wrangler secret put) ထဲမှာသာ ထားပါသည်။ ဒီနေရာမှာ ထည့်ရမှာက Worker URL နဲ့ admin token ပဲဖြစ်ပါသည်။

Firebase (Firestore)

Orders / Users / Payments / Logs ကို Firestore ထဲမှာ real-time သိမ်းမည်

✓ Firebase project linngametopupstore ကို ဒီ admin panel ထဲမှာ တိုက်ရိုက် ချိတ်ဆက်ထားပြီးပါပြီ — config ကို manual paste လုပ်စရာ မလိုတော့ပါ။ Authentication → Sign-in method → Email/Password ကို enable လုပ်ပြီး admin account တစ်ခု (Authentication → Users → Add user) ဖန်တီးထားရုံပဲ လိုပါတော့တယ်။
